# Sistema Escolar

## Visão Geral

O Sistema Escolar é uma aplicação web destinada ao gerenciamento acadêmico da instituição de ensino.

Seu principal objetivo é centralizar o cadastro de alunos, professores, turmas, disciplinas e lançamentos de notas, garantindo controle, rastreabilidade e segurança das informações.

---

# Objetivos

- Eliminar controles manuais em planilhas
- Centralizar informações acadêmicas
- Garantir rastreabilidade das alterações
- Controlar períodos de lançamento de notas
- Facilitar emissão de relatórios
- Melhorar a gestão escolar

---

# Perfis de Usuário

## Diretor

Responsável pela gestão acadêmica.

Permissões:

- Gerenciar usuários
- Gerenciar alunos
- Gerenciar professores
- Gerenciar turmas
- Gerenciar disciplinas
- Abrir períodos
- Fechar períodos
- Editar notas
- Consultar relatórios
- Consultar auditorias

---

## Professor

Responsável pelo lançamento de notas.

Permissões:

- Consultar turmas vinculadas
- Consultar disciplinas vinculadas
- Lançar notas
- Alterar notas durante período aberto
- Consultar histórico de lançamentos

---
