Este arquivo contem um prompt por agente definido em [.agents.json](../.agents.json).

Como usar:

1. Copie o prompt do agente desejado.
2. Substitua <DESCREVA_A_TAREFA_AQUI>.
3. Envie no chat para executar com aquela persona.
