# Git Workflow Oficial

## Objetivo

Padronizar desenvolvimento.

## Fluxo

main

↓

develop

↓

feature

↓

pull request

↓

review

↓

merge

## Branches Permitidas

main

---

## Nunca

Commitar diretamente na main.

Commitar código sem revisão.

Misturar funcionalidades distintas.
